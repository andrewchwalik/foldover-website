# Foldover website
Static marketing site hosted with GitHub Pages. Edit `index.html` for copy/sections, `style.css` for appearance, and `site.js` for illustrative sample-data phone previews and scenario cards. No real user data is included.

Preview: `python3 -m http.server 8090` from this folder.

Design follows the supplied layout: rounded white shell, centered hero and phone, three feature cards, staggered steps, two scenario cards, app CTA and footer. Illustrative device UI replaces fashion photography; scenarios replace unverified testimonials. App Store badges remain pending until a real listing exists.
